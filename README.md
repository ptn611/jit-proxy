# Jit Proxy

The jit proxy is a Solana program that aims to make it easier to provide JIT liquidity on Velocity. The jit proxy uses an MM's market and maximum position size to automatically create Velocity perp orders.

For more information on how to interact with the Jit Proxy program, see the README for the [typescript sdk](ts/sdk/Readme.md) or the Rust [jitter example](rust/).
